# Results Summary (Template)

Copy this file for each round of testing and fill it in. Only report what was observed. With 5 to 8 participants a percentage moves a lot when one person differs, so always show the count beside it.

Do not write any result into this template. The blanks are for real data from [`observation-sheet.csv`](observation-sheet.csv) and [`post-session-survey.md`](post-session-survey.md).
